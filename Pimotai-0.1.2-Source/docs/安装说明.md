# 拼模台 Windows 免安装说明

## 1. 下载正确的文件

在项目 GitHub 仓库的 **Releases** 页面，选择同一版本的：

- `Pimotai-版本-Windows-x64.zip`：Windows 客户包。
- `SHA256SUMS.txt`：用于检查下载是否完整。

请使用 Windows 10/11 的 x64 电脑和支持 WebGL2 的近期 Edge 或 Chrome。大模型需要较多内存，建议先用内置示例验证。ARM 版 Windows、虚拟机和远程桌面的图形能力需要自行验证，首版未提供对应原生包。

无需购买服务、注册账号、安装 Python、Node.js、CUDA 或视频生成模型。`Source code.zip` 和名称含 `Source` 的文件面向开发者，不是双击运行的客户包。

## 2. 核对 SHA256

在下载文件夹空白处右键，打开终端或 PowerShell，执行：

```powershell
Get-FileHash -LiteralPath '.\Pimotai-0.1.2-Windows-x64.zip' -Algorithm SHA256
```

版本变化时，将文件名换成实际下载的名称。把得到的 `Hash` 与同一 Release 的 `SHA256SUMS.txt` 中该 ZIP 对应的一行逐字符比较，大小写不影响结果。不一致时停止运行并重新从原 Release 下载。校验值检查文件一致性，本身不等于发布者身份认证。

## 3. 完整解压并启动

1. 右键 ZIP →“全部解压缩”，选择自己有写入权限的文件夹。
2. 打开解压后的文件夹，双击 **拼模台.exe**。
3. 保留出现的启动窗口。默认浏览器会打开工作台；没有自动打开时，复制启动窗口里的 `http://127.0.0.1:端口/` 地址到浏览器。
4. 点击“体验示例”，确认能看到模型、旋转视角并选择部件，再导入自己的文件。

必须保留 EXE 旁边的 `_internal` 文件夹。不要在 ZIP 内直接双击，也不要只把 EXE 拖到桌面；可给 EXE 创建快捷方式。程序不要求管理员权限，也不需要开放公网或局域网端口。

此首版可执行文件未进行商业代码签名，Windows 可能显示未知发布者提示。保持系统防护开启；先确认仓库和校验值，不确定时停止并向发布者核实，或请熟悉源码的人审阅后自行构建。不要关闭杀毒、防火墙或系统安全功能，也不要运行来源不明的“修复脚本”。

## 4. 基本操作

默认使用浅色界面，顶部“深色界面”按钮可切换主题。导入 STL、OBJ 或 3MF 后，在右侧查看部件和分析结果。拖动旋转，右键平移，滚轮缩放；底部滑块用于爆炸展开。“摆位”页可导入同源、同尺度参考，查看匹配候选并人工确认；也可手动调整位置、旋转和缩放。选中部件后记录“已打印”。

选中部件后可“从装配隐藏”或“加入装配”，只改变装配显隐，不删除该部件或原件。部件筛选中的“装配中”用于查看当前加入的部件，切回“全部状态”可找到隐藏件。显隐与打印状态分别记录并随工程保存。

导入会舍弃文件原有颜色、材质和贴图，按连通部件重新分配纯色，可在工作台中调整。首版 3MF 导入仅支持单模型文档的 core 结构；未知厂商的多文档装配或不支持的扩展，请先在原软件中导出 STL 再导入。

STL 不保存单位，请核对默认毫米是否正确。连通分件不能自动把焊接单壳拆成语义零件；没有参考的随机散件、缺件、对称件和重复件不能保证自动恢复。检查结果不能替代切片预览、尺寸实测和实际试装。

“导出显示 STL”保存所选部件当前摆位的显示网格；“导出装配 3MF”保存可见装配网格、支持的摆位信息和工作台当前的部件配色，最多50万面。超限时逐件导出STL，或用本机项目中的登记原件切片。显示网格可能是项目准备时的预览副本；需要原始打印精度时请核对并使用原件。STL 不保存颜色。进入切片软件后仍须检查尺度、方向、支撑与打印参数。

底部可选择“360°旋转”或“装配→展开”，再选择横屏或竖屏，点击“导出展示视频”。输出为WebM视频；需要支持录制与WebM编码的浏览器，不支持时换用近期Chrome或Edge。录制大模型时的流畅度取决于电脑和浏览器性能，导出展示视频不代表模型已通过装配验证。

### 大模型范围

单批导入最多64个文件、150MiB，单文件分析最多200万面；工程与参考模型合计最多800万面。`.pmt` 解压后的总量上限为384MiB；普通3MF预检仍为200MiB。工程能打开不代表能整体导出3MF，导出上限另为50万面。分批导入适用于多份较小文件，不能绕过单文件或工程总量限制。

### 可选的预装项目与原件

通用客户包不附带用户模型。另行取得本机项目包时，把其中的 `本机项目` 文件夹放到 **拼模台.exe 旁边**，目录应为 `本机项目/项目名称/manifest.json`、`project.pmt` 及 `originals/`。不要放到 `_internal` 或只复制预览工程而丢掉原件；补齐后重新启动程序。

工作台会列出有效的本机项目，在顶部选择后点击“打开所选项目”。预览工程与原始打印文件分开保存：查看项目用 `.pmt`，切片优先使用登记原件。原件下载接口只提供清单登记的文件；选中部件后的“拓竹打开原件”需要本机已安装 Bambu Studio，并只打开所选原件，不执行打印或登录。未找到软件时可下载原件，再手动用切片软件打开。已有切片工程尚未保存时，请按 Bambu Studio 提示妥善保存。

本机项目可单独备份、移动和升级，也可按模型原许可作为非商业项目附包分享，保留作者署名、来源链接、原README/许可与改动说明。通用发行包中的 MIT 许可不替代模型自身的许可。没有项目包仍可使用常规导入与工程功能。

## 5. 保存工程、升级和退出

请定期点击 **导出工程**，保存 `.pmt` 文件。这份文件包含本工作台支持的模型、摆位、配色、装配显隐和打印状态；以后通过“打开工程”继续。自动保存使用浏览器本地数据库，修改状态时增量保存，避免反复压缩所有几何；手动导出的 `.pmt` 仍是全量备份，压缩后不得超过150MiB，大工程导出可能需要等待。

浏览器本地缓存不等于备份，清理缓存、无痕窗口、换浏览器或换端口可能使原缓存不可见。输入文件保持在本机，软件不会上传模型。

升级前先导出工程；将新版完整解压到新文件夹，再导入备份。有本机项目时，把整份 `本机项目` 文件夹复制到新版 EXE 旁边并保留原备份。关闭浏览器标签只关闭界面；关闭启动窗口或在其中按 `Ctrl+C` 才会停止程序。卸载前单独保存工程和本机项目，再删除程序解压文件夹；若要清理浏览器缓存，请先备份工程，再在浏览器网站数据中删除对应 `127.0.0.1` 地址的数据。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 双击后找不到页面 | 查看启动窗口实际地址，复制到 Edge/Chrome。不要使用旧收藏的端口地址。 |
| 页面打开但显示空白或图形错误 | 更新浏览器，检查 WebGL2/硬件加速；先用本机桌面测试内置示例。记录错误，勿盲目重装系统。 |
| 提示资源或 DLL 缺失 | 重新完整解压原 ZIP，保留 `_internal`。检查下载校验值和系统防护记录，不要从陌生网站下载 DLL。 |
| 18777 已占用 | 启动器会自动换端口，使用窗口新地址；原进程不会被停止。换端口后通过 `.pmt` 载入工程。 |
| 打开后没有原工程 | 核对浏览器与地址是否相同，通过备份 `.pmt` 恢复；不要反复清缓存。 |
| 模型太慢、文件过大 | 核对单文件200万面、工程800万面和导出限制；按需减少副本三角面或分批导入，保留原文件。大装配切片用逐件STL或登记原件。 |
| 看不到本机项目或原件不可打开 | 核对 `本机项目` 在 EXE 旁边、清单和文件齐全；补齐后重启。预览工程可见不证明原件存在。 |
| 提示未找到 Bambu Studio | 先安装拓竹软件，或下载登记原件后手动打开；无需修改系统文件关联。 |
| 运行被系统安全功能拦截 | 保持防护开启，核实发布来源并反馈发布者；不要把关闭防护当作安装步骤。 |

反馈问题请提供版本号、Windows 版本、浏览器版本和报错文字。无需提供私人模型、账号密码或 GitHub token。
