# 给 AI 助手的拼模台安装指引

用途：用户可把本文件和项目 GitHub 仓库地址一起交给豆包、ChatGPT 或其他具备电脑操作能力的助手。目标是在 Windows x64 安装并验证官方便携包，保留已有工程。仅有对话能力的助手应给出可执行步骤，不能声称已点击、下载或验证。

## 执行范围

1. 确认用户提供的是项目仓库或 Release 地址。未提供地址时只询问这一关键信息，不猜测发布者、仓库或下载链接。检查系统是否为 Windows x64；其他平台说明首版适配限制。
2. 打开仓库 Releases，选择同一版本的 `Pimotai-版本-Windows-x64.zip` 和 `SHA256SUMS.txt`。禁止把 GitHub 自动生成的源码压缩包当作客户包。下载公开包不需要用户登录，也不需要个人访问 token。
3. 保存到用户可写目录，执行 `Get-FileHash -LiteralPath '实际ZIP路径' -Algorithm SHA256`，与同一 Release 的对应校验行逐字符比较。必须实际比较，不能凭文件名、大小或下载成功宣称校验通过。若不一致，停止运行，重新获取原 Release 文件并报告。
4. 完整解压到新文件夹，不覆盖旧版本、旧工程或原始模型。保留 `_internal`，不要仅拷贝 EXE，不在压缩包内直接运行。安装包无需系统 Python、Node.js、CUDA、H3、付费 API 或管理员权限。
   若用户另有合法取得的本机项目包，将完整 `本机项目` 文件夹复制到 EXE 旁边，保持 `本机项目/项目名称/manifest.json`、`project.pmt`、`originals/` 结构；不要放进 `_internal`。通用发行包不含用户模型，没有项目包仍可正常使用。升级前先备份旧项目包，不能用通用包覆盖或删除原件。
5. 双击 `拼模台.exe`。保留启动窗口，读取实际显示的 `127.0.0.1` 地址；浏览器未自动打开时手动打开。默认端口 18777，被占用会自动换端口；不要停止其他进程或改路由器、防火墙端口规则。
6. 验证工作台标题，点击“体验示例”，观察模型可见且可旋转，能选中部件。标记一个部件的打印状态，导出 `.pmt` 到用户允许的位置，再通过“打开工程”载入并核对状态。仅打开页面不等于全部功能验证通过。没有界面访问能力时明确说明尚未完成这些验证。
   当前界面默认浅色、可切换深色。安装验收应使用小示例验证“加入装配/从装配隐藏”及状态恢复；用户要求展示视频时再验证横屏/竖屏的360°旋转或装配→展开，输出WebM并受浏览器录制与编码支持影响。不能只看到下载提示就声称视频画面或帧率验收通过。
   若用户要求使用预装项目，再验证项目清单及工程能载入，并核对原件可用状态；只有预览不代表原件存在。Bambu Studio 的打开动作需由用户明确选件触发；没有此授权时不拿用户未保存的切片工程做安装测试。打开只交付登记原件，不发起打印、登录或远程控制。未安装时说明可先下载原件并手动打开，不擅自安装额外软件。
7. 告知用户程序位置、实际地址、停止方式和工程备份位置；报告完成了哪些验证及任何未解决问题。普通安装不需要操作用户的 GitHub 仓库。

## 安全和数据边界

- 保持 Windows 安全功能、杀毒与防火墙开启。首版 EXE 未商业签名，未知发布者提示不能被解释为已检测到恶意，也不能被无依据解释为“绝对安全”。确认来源和校验值仍有疑问时停止并向发布者核实；禁止自动点击忽略警告、关闭防护、添加排除目录或下载第三方 DLL。
- 不询问、不读取、不复制、不上传用户密码、明文 token、浏览器凭据或私人模型。不要登录用户的 GitHub、创建密钥或改变账号权限。
- 不替用户清理浏览器缓存、卸载旧版或删除工程。浏览器 IndexedDB 按浏览器和地址保存；换浏览器、换端口、无痕模式和清理数据可能导致旧缓存不可见。先从旧版导出 `.pmt`，再升级并载入。
- 软件只在本机处理模型，启动器仅提供网页、健康检查、登记的本机项目文件，以及带本机会话验证的“在拓竹中打开”动作。它不接受任意文件路径、命令或上传。不要为其开公网访问、添加自动启动、安装后台服务或修改全局 Python 环境。
- 项目模型的许可独立于程序的 MIT 许可。通用源码和通用客户包不自动包含用户模型；用户要求非商业分享时，可按模型原许可另做项目附包，保留作者署名、来源链接、原README/许可及改动说明。不要把非商业项目分享误作商用发布，也不要额外设置商业授权审批来阻断已获授权的非商业使用。
- 发布程序时只使用经过白名单筛选的源码和通用客户包；排除 `本机项目`、`宣传片`、`钢铁侠素材` 和依赖私有数据的迁移测试。通用本机项目接口测试仍属于公开测试，不能为规避失败而一并删除。

## 当前容量与保存方式

单批导入最多64个文件、150MiB；单文件分析最多200万面，工程与参考模型合计最多800万面。`.pmt` 解压后总量最多384MiB，普通3MF预检仍限200MiB。装配3MF导出最多50万面；大型工程可查看不代表能整体导出3MF，应逐件导出显示STL或使用登记原件。不要以分批导入或关闭检查的方式绕过单文件、总面数或解压限制。

自动保存使用IndexedDB分开保存几何并增量更新状态，不再每次重新压缩全部几何；缓存仍不是备份。手动导出`.pmt`仍是全量压缩备份，并检查压缩后不超过150MiB。测试保存与恢复时要核对摆位、颜色、装配显隐、打印状态及本机项目原件绑定，不能把自动缓存成功等同于备份文件完整。

## 遇到问题的处理顺序

读取启动窗口的准确报错 → 核对 ZIP SHA256 → 检查完整解压及 `_internal` → 用本机 Edge/Chrome 打开实际地址 → 测试内置示例 → 记录系统、浏览器、版本和错误。只做与报错相关的修复，不运行来源不明的脚本，不重装系统，不把私人模型上传到聊天平台。

注意能力边界：连通体拆分不等于语义分件；无参考散件不能保证自动拼回原模型；重复和对称候选需人工确认；STL 单位默认毫米，必须与原设计核对。安装成功不代表每份模型均可打印或已完成物理试装。
