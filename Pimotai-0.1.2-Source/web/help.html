从一个模型，开始你的制作计划

拼模台在你的浏览器中处理模型，启动器只提供本机页面。模型不会上传到服务器，无需注册或配置 AI 密钥。

第一次使用

  1. 解压下载的 Windows 压缩包，双击 拼模台.exe。保留运行窗口，页面会在默认浏览器打开。
  2. 点击“体验示例”熟悉操作，或拖入 STL、OBJ、3MF 文件。
  3. 左键拖动旋转、右键平移、滚轮缩放；点击模型或右侧卡片选择部件。
  4. 在“分析”中检查尺寸和网格边界。STL 不含单位，必要时选择原始单位换算为毫米。
  5. 按部件选择颜色、标记已打印。开启“打印进度透视”后，未打印部件半透明，已打印部件不透明。
  6. 点击“导出工程”保存 .pmt 文件。工程保留几何、配色、摆位、参考和打印状态，可在另一台电脑打开。

零件连线卡片

模型两侧的圆角卡片显示零件小图、文件名和逐件打印按钮，连线跟随实际三维位置。选择“全部”可滚动浏览全部卡片，“仅选中”聚焦当前零件，“关闭”保留纯模型视图。卡片与右侧列表共用打印状态，支持撤销和自动保存。隐藏、内部或备选件保留说明，未加入装配时不显示连线。

白模如何分件

按共享顶点的连通网格拆出部件，保留原来的位置。一个已经焊接成整体的实体不会自动切割成语义零件，也不会自动生成榫卯、支撑或可打印补片。只有颜色不同、几何连在一起的部分，仍可能是一件。

散件如何重组

  1. 在“摆位”页导入同源、同尺度、相同三角网格的完整装配作为参考。
  2. 选择一件，点击“匹配所选部件”。匹配是有范围限制的几何采样核验，并非 AI 理解未知模型。
  3. 对称件或重复件可能出现多个候选。选择后点击“应用并确认”，再检查接缝与方向。
  4. 没有可靠候选时，用移动、旋转、缩放手柄或坐标输入人工调整，再点击“确认此件摆位”。爆炸展开只是展示，不改变保存或导出的装配坐标。

导出与拓竹

“导出显示 STL”输出所选部件当前显示网格及实际摆位；“导出装配 3MF”输出装配中分件的配色与装配坐标（最多50万面，大型装甲请逐件导出或打开原件），可以在 Bambu Studio 中打开并安排打印。3MF 使用标准基础材料色，不包含拓竹打印机配置、耗材参数、AMS 槽位或已经切好的 G-code。请在切片软件核对尺寸、材料、摆盘和支撑。导入时按连通网格重新分件与配色，不保留源文件颜色、材质或 OBJ 的 MTL 贴图。首版 3MF 导入支持单模型文档的标准几何，多文档/厂商装配请先导出 STL；3MF 导出保留工作台设置的逐件纯色。

我的本机项目与打印原件

可选项目包放在程序旁边的“本机项目”文件夹，重启启动器后选择打开。工程保留分件配色、装配、隐藏状态和打印记录；默认隐藏的内部件、备选件仍在列表，选择“全部状态”可见。“加入装配／从装配隐藏”只控制整身展示；“单独查看”可以检查隐藏件。

“拓竹打开原件”打开注册项目包中的打印原STL；没有拓竹软件时可用“下载原件”保存。部分柔性件和手部使用弯曲或拼接预览，显示网格与打印原件有区别，按分件说明操作。工程.pmt保存显示网格，不包含另外注册的打印原件；迁移到另一台电脑时需同时带上本机项目包。程序MIT许可与模型自身许可分别适用，分享时保留项目作者、来源、许可和改动说明。

保存与恢复

当前工程会自动保存在此浏览器、此本机地址的存储里。几何首次写入后，后续配色、摆位和打印状态只增量保存，避免反复压缩大型装配。同一地址多标签共用当前工程缓存，以最后保存为准。更换浏览器、清理浏览数据或启动器改用端口后，自动保存可能看不到。因此建议每次完成阶段工作都导出工程备份。打开工程会替换当前工作区。撤销保留最近 25 次摆位和状态操作，不跨越导入和工程切换。

文件大小与检查范围

单批最多 64 个文件、150MB；整个工程最多 800 万三角面、500 个部件；单个分件的分析上限为 200 万面。参考匹配每个输入最多 20 万面。复杂项目建议分批。网格闭合检查和几何容积不能检测所有自交、碰撞、壁厚或承重问题，不能代替切片与实物装配验收。失败或取消分析会保留已有工程。

展示视频

选择“360°旋转”或“装配→展开”，再选择横屏或竖屏，点击“导出展示视频”。在支持 MediaRecorder 的浏览器中录制 12 秒 WebM；横屏目标1920×1080，竖屏目标1080×1920。此入口录制三维模型画面，不包含连线卡片和软件界面。复杂模型的帧率取决于电脑性能。录制时请保持页面打开，完成后自动下载。
